# みちつなぎサファリ

道のブロックを置いて、スタートからゴール（おうち）まで道をつなぎ、「しゅっぱつ！」を押すと動物が歩くプログラミング遊びです。
公開URL：https://shun-watanabe-cloud.github.io/michitsunagi-safari/

iPhone のホーム画面に追加して使う PWA です。一度追加すれば、ネットにつながっていなくても遊べます。

- 全10ステージ：まっすぐ → 曲がり角 → 岩・池をよける → まちがえ用のブロック入り → じゅうじ（交差）
- 星の数：ゴールで1つ、くだもの1つにつき1つ（最大3つ）。記録は端末の中にだけ保存します（送信はしません）
- 操作：下のブロックを盤面へドラッグする。またはブロックをタップしてからマスをタップする。置いたブロックはタップで戻せる
- キャラクター・絵・音はすべて独自のもの（絵文字と図形で描画）。他社アプリの素材は使っていません

## ファイル

| ファイル | 役割 |
|---|---|
| index.html / style.css / app.js | 画面と操作 |
| core.js | ステージデータと道のつながり判定（ステージを足すときはここの `LEVELS` を編集する） |
| sw.js | オフライン用。**ファイルを直したら `VERSION` の数字を上げる**（上げないと iPhone に古い版が残る） |
| manifest.webmanifest / icons/ | ホーム画面に追加したときの名前とアイコン |
| tests/core.test.js | 全ステージが解けるか確かめるテスト：`node tests/core.test.js` |
| tools/serve.js | PCで試す用のサーバー：`node tools/serve.js` → http://localhost:8765/ |
| tools/make_icons.ps1 | アイコン画像を作り直す |

## 公開のしかた（初回だけ・ネットが要る）

HTTPS で配信できる場所に、このフォルダの中身（tests・tools は不要）をそのまま置きます。例：GitHub Pages、Netlify、Cloudflare Pages。
※ Google Apps Script（GAS）の Web アプリでは Service Worker が動かず、オフラインで遊べないので使わない。

## iPhone への入れ方

1. Safari で公開した URL を開く（Chrome などでは不可）
2. 共有ボタン → 「ホーム画面に追加」 → 追加
3. ホーム画面のアイコンから一度起動して、ステージを1つ開く（これでオフライン用の保存が完了）
4. 以後は機内モードでも遊べる

## 更新のしかた

1. ファイルを直し、`node tests/core.test.js` が通ることを確認する
2. `sw.js` の `VERSION` を `v2`, `v3` … と上げる
3. 公開先に上書きする
4. 各 iPhone はネットにつながった状態でアプリを一度開き、閉じてもう一度開くと新しい版になる

## ステージの作り方（core.js の LEVELS）

```
map:  '.'くさ  'x'いわ  't'き  'w'みず  'S'スタート  'G'ゴール
      '-' '|' 'L'(うえ・みぎ) 'J'(うえ・ひだり) 'r'(みぎ・した) '7'(ひだり・した) '+'(じゅうじ) ＝正解の道
dir:   スタートから出る向き 0=うえ 1=みぎ 2=した 3=ひだり
holes: 子どもが置くマス。省略すると正解の道が全部パレットに出る
extra: まちがえ用に追加で出すブロック 例 { '-': 1 }
fruits: くだもののマス（2つ）
```
追加したら `node tests/core.test.js` で解けることを確かめる。
